# Community Language Packs 🌍

Official community translation repository for Android applications:

- [Links](Links/) - Community translations for **Links**
- [Apex](Apex/) - Community translations for **Apex**
- [Omicron](Omicron/) - Community translations for **Omicron**

## Repository Structure

Each application has its own folder containing:

- `languages_index.json`: Catalog index of available languages, metadata, and string counts.
- `languages/`: Downloadable JSON packs per locale (e.g. `en.json`, `es.json`, `ar.json`).

## Contributing

1. Navigate to the app folder you wish to contribute to (e.g. `Links/`, `Apex/`, or `Omicron/`).
2. Follow the translation guidelines in that directory's `README.md`.
3. Submit a Pull Request!
